# hex

A program to simulate, for a triangularly-tiled plane with hexagons of
particular radii, the expected number of steps on a random walk to exit a
particular hexagon. We take triangle side lengths to be 1, with two hexagons,
of radii 2 and 4.

```
radius := 2 => 7.342661
radius := 4 => 19.284958
```
