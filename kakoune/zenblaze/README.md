# zenblaze

A [zenburn](https://github.com/jnurmine/Zenburn) implementation for Kakoune,
with support for LSP and tree-sitter faces.

Most faces are commented with rationale as to how they've been adapted from the
Vim colorscheme. Faces which deviate from the Vim theme (e.g., `StatusLine`)
have commented options which restore a more faithful adaptation.
